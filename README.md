# 💥 BOOMZY · 붐지

> 아기자기한 파스텔톤 치비 캐릭터 6종이 겨루는 **8인 캐주얼 3D 탑다운 슈팅 대전** 웹 게임입니다.
> PC·모바일·태블릿 브라우저에서 바로 플레이할 수 있고, 에셋 다운로드 없이 모든 모델과 사운드를 코드로 생성합니다(빌드 전체 gzip 약 235KB).

기획 문서: [`doc/PASTEL_BRAWL_개발_프롬프트.md`](doc/PASTEL_BRAWL_개발_프롬프트.md)

## 🚀 실행

```bash
npm install
npm run dev        # http://localhost:5173  (같은 Wi-Fi의 폰/태블릿은 Network 주소로 접속)
npm run build      # client/dist 정적 빌드
npm test           # vitest 52개: 시뮬레이션 규칙 + 맵 5종 검증 + 봇 풀매치
npm run balance    # TTK / 슈퍼 충전 리포트 (기준: TTK 2.5~4.5초, 슈퍼 4~7회)
npm run botsim -w shared -- 200 desert          # 맵별 봇 플레이테스트 (매치 길이, 승률, 수풀 킬 비율)
npx tsx shared/scripts/allmaps.ts 60            # 전 맵 합산 캐릭터 승률
```

## 🎮 게임 소개

- **규칙**: 8인 개인전(봇이 빈자리를 채움). HP가 0이 되면 리타이어 → 관전. 최후의 1인 또는 3분 종료 시 최고 점수가 승리합니다.
- **수풀 은신**: 수풀 안에서는 보이지 않고, 밖에서 날아온 탄 피해가 30% 줄어듭니다. 공격하거나 맞으면, 또는 적이 2.5m 안으로 다가오면 노출됩니다.
- **슈퍼**: 적중할수록 게이지가 차고, 100%가 되면 강화 공격이 나갑니다. 지형(바위·수풀)도 파괴합니다.
- **파워 큐브, 자기장(독구름), 맵 이벤트**(회복 꽃·보급 상자·돌풍), 연속 처치, 현상금 왕관, 이모트, 30초 튜토리얼을 넣었습니다.

```
shared/   서버·클라이언트 공용 결정적 시뮬레이션 (온라인 서버로 그대로 이식 가능)
  data/     캐릭터 · 무기 · 슈퍼 · 가젯 · zod 검증 · 밸런스 계산
  sim/      world(이동·사격·슈퍼·큐브·자기장·이벤트·점수·얼음), bush(은신 규칙), bot(AI), nav(A*)
  map/      D4 대칭 맵 생성기 5종 (스폰 8 · 상자 12 · 길찾기 도달성 테스트)
client/   Vite + TypeScript + Three.js
  render/   툰 셰이더(광택·라벤더 그림자·림) + 컬러 라인아트 외곽선, 절차적 치비 리깅/애니메이션,
            맵 테마(나무 9종 · 바위 4종 · 수풀 3종 · 물 · 얼음), VFX 파티클, 로비 쇼케이스
  input/    PC · 모바일 트윈스틱 · 게임패드
  audio/    Web Audio 절차 합성 효과음 + BGM (레이어드 무기음, 연타 피치 상승, 잔향)
  ui/       HUD(미니맵·킬피드·누적 데미지·피격 방향), i18n(ko/en), 스타일
  game/     매치 컨트롤러(고정 스텝 시뮬, 히트스톱, 처치 슬로모션), 프로필/전적 저장
```

## ✨ 연출 하이라이트

- 하체는 이동 방향, 상체는 조준 방향으로 도는 분리 애니메이션. 무기별 공격 모션(샷건 펌프, 오버핸드 투척, 석궁 재장전 등)과 맞은 방향으로 젖혀지는 젤리 피격 반응
- 매 발사마다 머즐 이펙트·탄피·카메라 반동, 데미지에 비례한 히트스톱, 처치 시 슬로모션, 연타 데미지 숫자 누적
- 품질 자동 조절(Low/Medium/High), 블룸·그림자·잔디 밀도 단계 조절, 탭 비활성화 시 일시정지, 배터리 부족 시 30fps 제한, PWA
