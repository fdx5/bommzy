# 🎮 PASTEL BRAWL — 8인 캐주얼 3D 슈팅 대전 게임 개발 프롬프트 가이드

> 브롤스타즈 스타일의 아기자기한 파스텔톤 3D 웹 슈팅 게임을 **AI 코딩 도구(Claude Code 등)와 Blender**로 단계별 제작하기 위한 절차적 프롬프트 모음입니다.
> 각 단계의 `프롬프트` 블록을 순서대로 복사해 AI에게 전달하고, **완료 기준(체크리스트)** 을 통과한 뒤 다음 단계로 진행하세요.

## 0. 프로젝트 개요 (모든 프롬프트의 공통 컨텍스트)

아래 블록은 **모든 단계 프롬프트 앞에 붙여 넣는 마스터 컨텍스트**입니다.

```text
[프로젝트 컨텍스트 — PASTEL BRAWL]
- 장르: 탑다운(쿼터뷰) 캐주얼 3D 슈팅 대전, 8인 개인전(Free-for-All)
- 플랫폼: 웹 브라우저 (PC Chrome/Edge/Safari/Firefox + 모바일/태블릿 iOS Safari, Android Chrome)
- 아트 스타일: 아기자기한 치비(2.5등신) 캐릭터, 파스텔톤, 부드러운 툰 셰이딩, 둥근 실루엣
- 전장: 80m x 80m 정사각형, 나무 / 수풀(은신·엄폐) / 돌덩이(엄폐, 특수무기로 파괴 가능)
- 수풀 엄폐: 수풀 안에 들어가면 적에게 보이지 않고(은신), 수풀 밖에서 날아오는 탄의 피해가 줄어듦.
  공격·근접·피격 시 노출, 수풀은 슈퍼로 제거 가능 (상세 규칙은 '4-1. 수풀 엄폐 시스템' 참고)
- 규칙: 탐색 → 교전 → HP 0이 되면 리타이어(관전 모드), 최후 생존 또는 제한시간 내 최고 점수 승리
- 캐릭터 6종: 따발총 / 샷건 / 수류탄 / 석궁 저격 / 부메랑 / 버블건
- 특수무기(슈퍼): 공격 적중 시 게이지 충전 → 100% 시 강화 발사, 데미지 업그레이드 + 지형(돌) 파괴
- 멀티플레이: 서버 권위(authoritative) 실시간 멀티, 매치메이킹, 봇 채우기
- 점수 저장: 계정(게스트/닉네임) 별 누적 점수, 전적, 리더보드
- 기술 스택:
  - 클라이언트: TypeScript + Vite + Three.js (WebGL2, WebGPU 선택적)
  - 물리/충돌: 자체 2D 원·AABB 충돌(서버/클라 공유 코드)
  - 서버: Node.js + Colyseus (WebSocket), 20Hz 서버 틱, 60fps 클라이언트 보간
  - DB: PostgreSQL(전적/점수) + Redis(세션/리더보드 캐시)
  - 에셋: Blender 4.x → glTF 2.0(.glb), Meshopt 압축, KTX2(Basis) 텍스처
  - 모노레포: /client /server /shared /assets-src(blend 원본)
- 품질 목표: 모바일 중급기 기준 60fps(최소 30fps), 초기 로딩 < 8MB, 입력 지연 체감 최소화
```

## 2. Blender 에셋 제작 (캐릭터 · 맵)

### 2-1. 공통 아트 가이드

```text
[아트 바이블]
- 팔레트(파스텔): 민트 #A8E6CF, 피치 #FFD3B6, 코랄 #FFAAA5, 라벤더 #C3B1E1,
  레몬 #FFF5BA, 스카이 #B5DEFF, 핑크 #FFC8DD, 크림 그라운드 #F6EEDF, 잔디 #BFE3A8
- 셰이딩: 2~3단 툰 램프 + 부드러운 림라이트, 외곽선은 Inverted Hull(두께 0.015)
- 형태: 큰 머리(전체 키의 45%), 둥근 손발, 날카로운 모서리 금지(Bevel 필수)
- 조명 기준: 따뜻한 키라이트(#FFF1DC) + 하늘색 앰비언트(#CFE8FF), 그림자 색은 검정 대신 보라빛(#8A7FB5)
- 폴리곤 예산: 캐릭터 3,000~5,000 tris / 나무 600~1,200 / 수풀 200~400 / 돌 300~600
- 텍스처: 512x512 그라디언트 팔레트 아틀라스 1장 공유(UV를 색 칸에 배치) → 드로우콜 최소화
```

### 프롬프트 2 — Blender 캐릭터 제작 자동화 스크립트

```text
[마스터 컨텍스트 + 아트 바이블 첨부]

Blender 4.x Python(bpy) 스크립트 /assets-src/blender/build_character.py 를 작성해줘.
1. 치비 베이스 메시 생성: 큰 구형 머리 + 캡슐 몸통 + 둥근 팔다리, Subdivision 1 → Apply,
   Bevel/Smooth Shading 적용, 전체 높이 1.2m, 원점은 발 밑
2. 캐릭터별 액세서리 파라미터화(JSON 입력):
   - 토토: 곰귀, 헬멧, 고글, 배낭 탄창 / 부기: 불도그 볼살, 카우보이 모자, 앞치마
   - 포포: 펭귄 부리·날개, 공사 헬멧 / 루나: 여우 귀·꼬리, 별 망토
   - 키키: 원숭이 귀·꼬리 리본, 탐험 모자 / 몽글: 문어 다리 6개, 잠수 헬멧, 버블 탱크
3. 무기 메시를 별도 오브젝트로 만들고 오른손 본(hand.R)에 Child Of
4. 공유 팔레트 아틀라스 텍스처로 UV 자동 배치(파트별 색상 칸 매핑)
5. 툰 머티리얼: glTF 호환을 위해 Base Color 텍스처 + 버텍스 컬러 AO 베이크
   (실제 툰 셰이딩은 Three.js 커스텀 셰이더에서 처리)
6. Rigify 대신 경량 리그(본 20개 이하)를 자동 생성하고 Automatic Weights
7. 애니메이션 액션 생성(NLA 트랙 분리): Idle, Run, Attack, Super, Hit, Death(리타이어), Victory
   — 스쿼시&스트레치 과장, 루프 애니메이션은 24fps 기준 16~24프레임
8. glTF 익스포트: .glb, +Y Up, Apply Modifiers, 애니메이션 포함, 머티리얼 Export,
   출력 /client/public/models/characters/{id}.glb
CLI 실행 예시: blender -b -P build_character.py -- --config configs/toto.json
```

### 프롬프트 3 — Blender 맵 오브젝트 & 레이아웃

```text
[마스터 컨텍스트 + 아트 바이블 첨부]

/assets-src/blender/build_props.py 와 build_map.py 를 작성해줘.

[build_props.py]
- 나무 3종(둥근 솜사탕 수관 / 원뿔 소나무 / 사과나무), 수풀 2종(둥근 덤불, 키 큰 풀), 돌 3종(작/중/대)
- 돌은 파괴 연출용으로 Cell Fracture 기반 파편 메시(6~10조각)를 별도 .glb 로 함께 익스포트
- 모든 소품은 바닥 원점, LOD0/LOD1(50%) 두 단계 생성
- 나무 수관은 바람 흔들림용으로 버텍스 컬러 R채널에 높이 가중치 저장

[build_map.py]
- 80m x 80m 바닥(크림/잔디 패치 그라디언트), 테두리는 낮은 울타리와 꽃 화단
- 레이아웃 원칙:
  - 8개의 스폰 지점은 외곽 원형 균등 배치(반경 34m), 각 스폰 주변 6m는 안전지대
  - 중앙 20m 원형 광장은 오픈 교전 구역 + 파워 큐브 상자 등장 지점
  - 수풀 띠(은신로)를 대각선 4방향으로 배치, 돌 엄폐물 그룹 24~32개, 나무 40~60그루
  - 좌우·상하 대칭(공정성)
- 배치 결과를 /shared/data/map_meadow.json 으로 출력
  (type, position, rotation, scale, collider{shape:'circle'|'box', size}, destructible, hp)
- 시각 메쉬는 정적 배치 병합(Join) 후 하나의 map_meadow.glb, 단 파괴 가능 돌은 개별 오브젝트로 유지
- 라이트맵(AO + 부드러운 그림자)을 1024px 로 베이크해 바닥에 적용
```

**완료 기준**
- [ ] 캐릭터 .glb 1개당 ≤ 400KB(Meshopt 압축 후), 맵 전체 ≤ 2.5MB
- [ ] Blender 렌더 미리보기에서 6캐릭터 실루엣만으로 구분 가능
- [ ] `gltf-transform optimize` 파이프라인 통과(npm run assets)

## 3. 클라이언트 렌더링 & 그래픽 품질

### 프롬프트 4 — 프로젝트 셋업 & 렌더 파이프라인

```text
[마스터 컨텍스트 첨부]

/client 를 Vite + TypeScript + Three.js 로 셋업하고 다음을 구현해줘.
1. 렌더러: WebGL2, antialias는 기기 성능에 따라 FXAA/MSAA 자동 선택, devicePixelRatio 상한 2(모바일 1.5)
2. 카메라: 쿼터뷰 퍼스펙티브(FOV 35°, 피치 55°), 플레이어를 부드럽게 추적(lerp + 진행방향 쪽으로 2m 앞당김),
   피격 시 미세 카메라 셰이크, 슈퍼 발사 시 짧은 줌 펀치
3. 툰 셰이더(ShaderMaterial / onBeforeCompile):
   - 3단 램프 셰이딩, 보라빛 그림자 색, 프레넬 림라이트(파스텔 화이트)
   - Inverted Hull 외곽선 패스(캐릭터 전용, 팀/적 색 구분 가능)
   - 나무·수풀 버텍스 셰이더 바람 흔들림
4. 수풀 은신 표현: 플레이어가 수풀 안에 있으면 해당 수풀 반투명(디더 페이드) + 본인 캐릭터 실루엣만 보이게,
   적이 수풀 안에 있으면 숨김(근접 2.5m 이내 또는 공격 시 노출)
5. 그림자: 단일 방향광 + 캐릭터 주변만 덮는 타이트 섀도 카메라(1024px), 저사양에선 블롭 섀도로 대체
6. 포스트프로세스(고사양만): 부드러운 Bloom(슈퍼 이펙트 강조), 약한 비네팅, 컬러 그레이딩 LUT(파스텔 보정)
7. 품질 프리셋 Low/Medium/High 자동 감지(첫 3초 평균 FPS 측정) + 설정에서 수동 변경
8. 에셋 로더: GLTFLoader + MeshoptDecoder + KTX2Loader, 로딩 진행률 UI, 캐릭터는 SkeletonUtils.clone 으로 인스턴싱
9. 나무/수풀/돌은 InstancedMesh 로 렌더링(드로우콜 목표 < 80)
```

### 프롬프트 5 — 이펙트(VFX) & 사운드

```text
[마스터 컨텍스트 + 아트 바이블 첨부]

귀엽고 타격감 있는 VFX/SFX 시스템을 만들어줘.
- 오브젝트 풀링 기반 파티클 시스템(GPU 인스턴싱)
```

```text
[마스터 컨텍스트 첨부]
```

## 11. 🕹️ 게임성 강화 (재미 설계)

### 11-1. 핵심 재미 루프

```text
탐색(수풀 매복·정찰) → 교전(조준·회피·엄폐) → 슈퍼 충전 → 역전 한 방(지형 파괴)
→ 파워 큐브로 성장 → 자기장 압박으로 최종 결투 → 결과·보상 → 다음 판
```

### 11-2. 추가 게임 요소

| 요소 | 내용 | 재미 포인트 |
|------|------|------------|
| **파워 큐브 상자** | 맵 곳곳 상자(HP 보유) 파괴 시 큐브 드롭, 큐브 1개당 HP·데미지 +10%, 처치 시 상대 큐브 흡수 | 성장·역전, 파밍 vs 교전 선택 |

| **이모트** | 감정표현 4슬롯 휠(웃음/화남/GG/하트), 리타이어 중에도 사용 | 소셜·귀여움 |

| **성장/보상** | 계정 레벨, 캐릭터 숙련도(트로피), 스킨·이모트 해금(유료 결제 없이 플레이 보상) | 재방문 동기 |
| **튜토리얼** | 30초 인터랙티브 튜토리얼(이동→조준→수풀 숨기→슈퍼로 돌 부수기) | 초보 진입장벽 ↓ |
