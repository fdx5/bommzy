# BOOMZY 0.3 — 무기와 맵 확장

기존 상점의 게임 내 골드로 무기를 구매합니다. 현금 결제는 추가하지 않습니다. 모든 캐릭터가 구매한 무기를 장착할 수 있고, 장착 상태는 계정과 캐릭터별로 저장됩니다. 기본 공격만 교체하며 캐릭터 고유 특수기는 원래 성능을 유지합니다.

| 무기 | 가격 | 기본 계열 |
|---|---:|---|
| 볼트 리피터 | 30,000 | 따발총 |
| 엠버 샷건 | 37,000 | 샷건 |
| 코멧 박격포 | 44,000 | 수류탄 |
| 오로라 석궁 | 51,000 | 석궁 |
| 프리즘 부메랑 | 58,000 | 부메랑 |
| 타이달 버블건 | 65,000 | 버블건 |
| 소닉 크라운 | 73,000 | 포효 파동 |
| 노바 클로 | 82,000 | 발톱 |
| 이온 카빈 | 91,000 | 따발총 |
| 이클립스 런처 | 100,000 | 수류탄 |

신규 무기는 기본형 대비 피해 6~8% 증가, 재장전 3% 단축입니다. 무기별 장착 모델, 투사체 모델, 발사·비행·적중 효과, 합성 발사음과 적중음을 추가했습니다. 상점에 성능과 장착 설명을 표시하며 미리보기, 캐릭터 화면, 조준선, 탄창 UI에 실제 장착 무기를 반영합니다.

기존 7개 맵의 지형과 경로를 교체하고 해저 항구, 잿불 용광로, 대나무 고개, 네온 교차로, 수정 동굴, 하늘 정원을 추가했습니다. 총 13개 맵입니다. 공통 방사형 광장을 제거하고 맵마다 다른 길과 배치를 사용합니다. 새 맵은 각기 다른 색상과 오브젝트 조합을 사용합니다. 시작 지점의 안전 공간과 지형 간 연결은 자동 검사합니다.

CPU 이동에서는 막힌 상자 중심으로 경로 끝점을 덮어쓰던 문제, 마지막 경로 모퉁이를 가로지르던 문제, 상자 자신을 사격 시야의 장애물로 판정하던 문제를 수정했습니다. 이동 가능한 방향으로 교전·회피 동작을 보정하고, 경로 실패 시 장애물로 직진하지 않도록 했습니다. 도달할 수 없는 적의 위치 대신 주변의 도달 가능한 사격 위치를 찾고, 좁은 틈에서는 실제 캐릭터 크기를 사용해 탈출 경로를 찾습니다. 정체 감지와 재탐색을 강화하고 매복 대기를 줄였습니다. 근거리 특수기를 사용할 때는 유효 거리로 접근하고, 보관한 특수기도 사용합니다.

밸런스는 캐릭터 체력, 따발총 탄퍼짐, 수류탄의 피해·폭발 반경과 특수기 배율, 부메랑 속도·판정 크기, 포효 파동 성능을 조정했습니다. 기본 무기의 예상 처치 시간은 평균 체력 기준 2.70~4.16초입니다. 봇 시뮬레이션은 맵별 80판씩 실행합니다. 시뮬레이션 승률은 플레이어 경기의 승률을 보장하지 않으므로 실제 플레이 피드백에 따라 추가 조정할 수 있습니다.

매치 제한시간은 240초에서 270초로 늘렸습니다. 독구름의 일반·조기 시작도 각각 30초 늦췄습니다. 최후의 1인이 남으면 제한시간 전에도 종료합니다. 결과 API는 새 맵과 늘어난 시간을 허용하며, 기존 계정과 구매 기록은 유지합니다.

자동 테스트 131개, 타입 검사, 밸런스 검사, 배포 빌드와 격리 API 검사가 통과했습니다. API 검사에서는 무기 구매 10회와 캐릭터별 장착 80회, 잔액·중복 구매·인증·슬롯·해제·구매 기록, 신규 맵 결과 제출을 확인했습니다. 최종 1,040판 봇 시뮬레이션에서 공격·회복·매복·기절 대기를 제외한 3초 이상 정체는 1건이었습니다. 이는 자동 시뮬레이션의 관찰 결과이며 모든 상황에서 정체가 없음을 보장하지 않습니다.

검증 명령:

```sh
npm test
npm run typecheck
npm run balance
npm run build
node server/test/release.mjs
npx tsx shared/scripts/allmaps.ts 80
```

API 검증은 임시 SQLite 데이터베이스와 별도 서버 프로세스를 만들고 종료 후 정리합니다. 실제 계정이나 운영 데이터베이스를 수정하지 않습니다. `--serve`를 붙이면 검사 후 8993 포트에서 브라우저 확인용 서버를 유지합니다.
