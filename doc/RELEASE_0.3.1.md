# BOOMZY 0.3.1 — 12인 대전

일반 대전 인원을 12명으로 늘렸습니다. 로컬 플레이어 1명과 CPU 11명이 참가하며, 모든 맵에 30도 간격의 독립된 시작 위치 12개를 사용합니다. 추가 시작 지점의 안전 공간을 확보하고 외곽 엄폐물과 일부 수풀을 보완했습니다.

대기 화면은 12칸으로 표시합니다. HUD, 점수판, 최종 순위, 9~12위의 배치 점수·트로피·경험치와 서버 결과 저장을 12인 기준으로 처리합니다. 서버는 최대 11처치·11도움까지 허용하며 13위 이상이나 12처치·12도움 결과를 거부합니다. 경기 제한시간은 4분 30초입니다.

수풀 상호작용 셰이더와 동시 특수기 표시 용량도 12명에 맞췄습니다. 공통 참가 인원은 `MATCH_PLAYER_COUNT`로 관리하며 튜토리얼은 기존처럼 플레이어와 연습 상대만 사용합니다.

자동 테스트 133개, 타입 검사, 배포 빌드, 격리된 API 검사가 통과했습니다. 13개 맵에서 32판씩 총 416판의 12인 CPU 경기가 정상 종료됐고, 측정 기준상 3초 이상 비전투 정체는 관찰되지 않았습니다. 브라우저에서 12개 참가 슬롯, 12개 캐릭터 표시와 `12/12` HUD, 렌더링 오류가 없는 것을 확인했습니다.
